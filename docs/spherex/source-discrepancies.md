# Where the SPHEREx sources disagree with each other

> **This file is our own analysis, not an official document.** Written 2026-11-14 by comparing the other files in this folder. Each row names the two places that differ, so you can check the original. The documents are living documents; some of these may be fixed by the time you read this.
> **How to use it:** when a value from this list matters to the code (a band edge, a keyword name, a size), do not pick one source. Read it from the real file (header, `WCS-WAVE`/spectral WCS) or from the SIA2 result.

| # | Topic | What one source says | What another says | Practical consequence |
|---|---|---|---|---|
| 1 | **Band wavelength ranges and resolving power R** | User Guide (`user-guide-data-products.md`): B1 0.75-1.09 µm R=39; B2 1.10-1.62 R=41; B3 1.63-2.41 R=41; B4 2.42-3.82 R=35; B5 3.83-4.41 R=112; B6 4.42-5.00 R=128. IRSA mission page: rounded ranges, same R values. | Bock paper Table 2: B1 0.75-1.11 R=41; B2 1.11-1.64; B3 1.64-2.42; B4 2.42-3.82 R=35; **B5 3.82-4.42 R=110; B6 4.42-5.00 R=130**. Akeson: SW side 0.75-2.44 µm, LW side 2.40-5.01 µm. | The band edges are nominal and bands overlap slightly. Never hard-code them. Get wavelength per pixel from the spectral WCS (`CWAVE`/`CBAND`) or, for visualization only, `WCS-WAVE`. |
| 2 | **Size of one spectral image file** | User Guide: about **70 MB** | Explanatory Supplement: about **67 MB**; Akeson paper: **72 MB** | Use only as a rough guide for download budgeting. |
| 3 | **Date the QR2 PSF header was corrected** | User Guide (releases page), PSF error page, Explanatory Supplement: **March 31, 2026** | IRSA mission page release list: **April 10, 2026**; QR overview: "April 2026". The `+psffix1` suffix in `VERSION` is the reliable marker. | Test the `VERSION` string, not a date. |
| 4 | **Launch date** | Explanatory Supplement: **12 March 2025, 03:10:12 UTC** | Bock and Akeson papers: **11 March 2025**. IRSA pages: "March 2025". | Probably a UTC vs. local-time difference (not stated). Write "March 2025" unless you need the day. |
| 5 | **Number of ePSF rows/zones** | User Guide: 21 x 21 zones for detectors 1, 2, 4, 5, 6 and **11 x 41 for detector 3**. Explanatory Supplement: 441 rows, and **451 rows for detector 3**. | Intro notebook: "21 x 21 grid ... 441 rows" with no mention of detector 3. PSF notebook: "the number of zones in x and y direction may vary depending on the version of the ePSF". | Do not assume 441 rows or a square grid. Read `BINX`/`BINY`/`NAXIS2` from the table (the PSF notebook does this). |
| 6 | **Which "PSF" text applies to a cutout** | The User Guide's "Cutouts of Spectral Image MEFs" section describes a **121-plane, 11 x 11 PSF cube** and the `XCTR_i`/`YCTR_i` keywords. | DR1 and QR3 files contain an **`EPSF` binary table** instead (PSF notebook, Explanatory Supplement). That guide section describes the old QR2 `PSF` layout. Akeson v2 also still says `PSF`. | For DR1/QR3, follow `tutorial-psf-in-cutouts.md`, not the plane-index steps in the guide. The two notebook rules are: image `VERSION` < 7.0 has `PSF` (QR1/QR2), `VERSION` >= 7.0 has `EPSF` (QR3/DR1). |
| 7 | **Pipeline version of QR3** | PSF notebook: "Versions after (including) 7.0 ... are QR-3 and DR1 data." | Explanatory Supplement: the first Survey 3/4 weeks (May 16 - July 19, 2026) were first processed with **6.5.6**, and their QR3/R7 versions are released with DR1. The docs do not say whether the 6.5.6 versions are still in the archive. | Don't assume release name implies pipeline version. Check `VERSION` in the primary header of each file. |
| 8 | **Header keywords for the planned pointing** | Explanatory Supplement text: `SPS_LON_ECL`, `SPS_LAT_ECL`, `SPS_PA_ECL` (underscores lost in the PDF text). | Same document's Appendix A example header: `SPS_ELON`, `SPS_ELAT`, `SPS_EPA`. | Look at a real header before using either name. These keywords are what identifies Survey 1-4. |
| 9 | **Length of a small slew** | Akeson paper: small slews "offset by 17'". | Bock paper: small slews of **11.8 arcmin**. | Not needed for data access; just don't quote either without checking. |
| 10 | **Where the DOIs are** | IRSA mission page: "No DOI" given. QR overview: DOIs for **QR1, QR2, QR3** only. | DR1 overview: **10.26131/IRSA678** (spectral images) and **10.26131/IRSA679** (All-Sky Cube). | Cite the DOI of the release you used; DR1 and QR3 together are one processed set, so cite both if you use both. |
| 11 | **`FLAGS` definitions** | Supplement Table 16 lists 23 flags with bit numbers (see `explanatory-supplement-extracts.md`). | The real `FLAGS` header has `MSKN####`/`MSKD####` keywords (intro notebook). The all-sky cube uses `MP <FLAG NAME>` keywords (Supplement Sect. 3.4). | Always list the flags from the file's own header and compare with Table 16 before masking. |
